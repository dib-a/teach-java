# Exercise 1: Hello

Your first program: make the computer say hello!

## Your mission

Open `HelloImpl.java` and make the program print:

```text
Hello, World!
```

## What you have

| File                 | What it is                                      | Can I change it? |
|----------------------|-------------------------------------------------|------------------|
| `Hello.java`         | The **interface**: it says what `Hello` can do  | No               |
| `HelloTest.java`     | The **test**: it says what is expected          | No               |
| `Main.java`          | Starts the program and prints the greeting      | No               |
| `HelloImpl.java`     | The **implementation**: this is where you work  | **Yes!**         |

## Step by step

1. Run the tests. They will not even compile yet. That is fine, the error is a hint!
2. Read the error message. What is it telling you?
3. Read `Hello.java` and `HelloTest.java`. What does the test expect?
4. Write your code in `HelloImpl.java`.
5. Run the tests again. Green means you did it!
6. Run `Main` and see your greeting on the screen.
